Some group work depends on files or tools on one person's computer: the budget for a family trip, a class project's code, or the build your friend needs help fixing. Connect that computer to an [Agent chat](/chat-and-agent-modes), then ask a shape to help you work on it together. The chat shows requests, progress, and results while the shape works on the computer you authorize.

You stay in control. You set your computer up once, allow it one chat at a time, and can remove access whenever you want.

<Warning>
  When you allow a chat, Shapes there can run commands, read and change files, use apps, control the keyboard and mouse, see your screen, and use the network, within the system permissions you give your computer. Results you ask for may be visible to other people in the chat. Only allow chats you trust.
</Warning>

## Choose where the work runs

- **Your connected computer:** use files, apps, and tools on that machine. Local Codex or Claude Code uses the setup and accounts already there. The computer needs to stay online.
- **Hosted Claude Code or Codex:** use coding agents run by shapes.inc. They do not use your computer or its local sign-in. See [hosted coding limits](/faq/how-do-free-coding-agent-limits-work) for allowances and billing.
- **Code Projects:** connect a GitHub repository and its saved environment to coding work in a chat. This is separate from connecting a personal computer. A project starts private and has its own [sharing controls](#code-projects).

Name the computer or project in your request, especially when you have both personal and shared access. For example, “Review the project on Maya's shared computer using her local Codex.” A shape should report an unavailable computer or agent rather than silently moving the task somewhere else.

## Set up your computer once

1. Open **Settings** → **Computers**.
2. Under **Add a computer once**, select **Copy install command**.
3. Run the command in Terminal or PowerShell on the computer you want to use. Setup requires Node.js 18 or newer.
4. Open the link setup gives you and approve the computer for your shapes.inc account. Only approve if you started setup on that computer and its terminal shows the same code.
5. Grant the system permissions your computer asks for, then let setup finish. You can close the terminal afterward; the connection keeps running in the background and starts when you sign in to your computer.
6. In **Settings** → **Computers**, select **Check for my computer**.

Your computer appears under **Your computers** as **Online** or **Offline**. Keep it on and connected to the internet while Shapes work on it. If it goes offline, it reconnects when it's on, signed in, and online, and its chat permissions are saved. Open **Permissions & background status** on a computer to see which system permissions it has.

### Use your computer from your phone

After setup, you can open the same shapes.inc account on your phone, enter the group's Agent chat, and use **+** → **Connect your computer** to choose your online computer and allow the chat. Ask the shape to read a named file or run a task there, then review its reply on your phone. The work still runs on the connected computer, which must stay on and online. Other chat members can read what the shape shares in the conversation; they do not gain access to your machine just because you are using it from your phone.

## Allow a chat to use it

1. In an Agent chat, open the composer's **+** menu → **Connect your computer**. You can also select the connect link in a Shape's reply when it asks for your computer.
2. Choose a computer.
3. Select **Allow in this chat**.

If you opened the dialog from a Shape's reply and the computer is online, the button reads **Allow and continue**. It allows the chat and asks the Shape to resume your request, so you don't need to retype it.

Allowing a chat lets your own requests there use your computer. Other members can't use it unless you [share it](#share-your-computer-with-chat-members).

To stop, open **Connect your computer** again and select **Remove chat access**, or **Change computer** to use a different one. **Remove computer** in **Settings** → **Computers** removes it from your account and stops access in every chat.

## Approve requests in the chat

When a task on your computer needs a permission or an answer, a **Computer task** card in the chat asks you to approve or answer. Nothing is chosen for you, and the task continues only after you respond. Only you can answer for your computer.

The card's status describes the task on your computer. Check the Shape's reply for the result, such as whether a change was made.

## Hand coding work to Codex or Claude Code

Shapes can hand parts of a task to Codex or Claude Code on your computer. These tasks start quickly and show their progress live in the chat. They run with the Codex or Claude Code setup and accounts already on your computer.

Ask a shape to remember a preference for this chat, then check that it confirms saving it. You can review saved preferences in [Memory](/memory):

> Always use a thread and my local Codex for code changes in this chat.

## Code Projects

Code Projects connect GitHub repositories for code tasks in an Agent chat. They're under **AI settings**, which chat owners can open; in a DM with a Shape, you can open it yourself.

1. Open the chat's **Settings** → **AI settings** → **Code Projects**.
2. Select **Connect GitHub**, or **Add Org** to install the shapes.inc GitHub App on another account or organization.
3. Select **New Project**, choose the **GitHub account** and **Repository**, and add optional **Workflow steps** and **Project instructions**.
4. Select **Create Project**.

New projects are private: only you can use them. To let the chat use one, open the project's editor and select **Share with members**. Read what members will be able to do, check the box to authorize them, and select **Share with members** again. Current and future chat members can then run code and publish changes using the project's repositories and saved environment, including secrets, and can edit its environment and instructions. Your personal GitHub connection stays private. **Stop sharing** removes future access but doesn't undo changes already published or files already downloaded.

Projects keep going after the first step. Shapes can continue in the same repository, keep results from background runs, and push a branch without opening a pull request when you ask.

For a group project, one person can connect the repository and share the Code Project. Another member can ask a shape to investigate a failing test; the group can review the explanation and then request a fix. Ask for the changed files and test result in the chat. If you request publication, check the returned branch or pull-request link in GitHub. Sharing the project permits those actions; it does not mean a task has already run or a change has been published.

## Share your computer with chat members

You can let specific members use your computer in a chat where you've allowed it.

1. Open **Connect your computer** in that chat.
2. Under **Shared computer access**, find **Share my computer in this chat** and choose up to 50 members.
3. Choose the permission:
   - **Read-only**: members can read files and ask Codex or Claude Code for read-only work. Commands, file changes, and opening apps are blocked.
   - **Can make changes**: members can run commands, change files, open apps, and use Codex or Claude Code to make changes with your local accounts.
4. Choose when access ends: **1 hour** or **24 hours**.
5. Select **Save access**. Saving replaces the computer's current shared access in that chat.

Each share shows its permission, who has it, and when it expires. Select **Revoke** to end it early. Shapes check the current permission before every action, so revoking or expiry applies to the next action; it doesn't undo work already done. Only you can share your computer, and members who leave the chat lose access.

## Work together on a connected computer

### Bring a local file into the discussion

Maya has the trip budget on her laptop. The rest of the family needs to compare two accommodation options.

1. Maya connects her computer, allows the family chat, and asks the shape to read the named budget file and summarize the relevant totals in that chat.
2. Everyone compares the summary and adds missing requirements. They can discuss what Maya shared without getting access to her computer.
3. Maya asks for any further file reads or changes herself, or explicitly [shares computer access](#share-your-computer-with-chat-members) with selected people.

Give the file's location and the question you want answered. Check the figures against the original file before deciding. A summary in the chat is shared information; it does not give other members permission to browse the rest of the computer.

### Let a friend review without changing files

For a class project, Maya can share **Read-only** access with Drew. Drew then asks a shape to review the named folder on Maya's computer, or use her configured local Codex or Claude Code for a review. The shape can post findings in the chat or the [thread](/threads) where Drew asked.

Read-only access supports file reads and agent inspection, not direct commands, edits, or opening apps. If the next step requires changes, Maya must save **Can make changes** access for Drew before Drew's request can make them. Saying “you can edit it” in the conversation does not change that saved permission.

### Make a change and review the result together

With **Can make changes** access, Drew can ask the shape to use Maya's named computer to fix a specific issue and run the relevant checks. For example: “Fix the date calculation in this project, run its tests, and leave the changes for us to review.” The local agent uses Maya's installed setup and accounts.

Keep the computer online while the job runs. Ask for the changed files, check results, and any unfinished steps in the conversation, then inspect the actual files on that computer. A started job or finished status alone does not prove that the requested fix worked or that a branch was published. Revoking access prevents later actions; do not assume it cancels work already running.

## Troubleshooting

### Connect your computer isn't in the + menu

It appears only in Agent chats. Ask a chat owner to switch the chat to **Agent**; see [Chat, Agent, and Auto](/chat-and-agent-modes#switch-an-existing-chat).

### My computer shows Offline

Make sure it's on, signed in, and connected to the internet, then select **Check for my computer** in **Settings** → **Computers**. If it still does not reconnect, use **Copy restart command** on the offline computer's card and run it on that computer. On macOS, you can also open **shapes.inc Bridge** from Applications.

### The setup code doesn't work

The code may have expired. Run the install command again to get a new code.

### I can't share my computer

First allow your computer in that chat. You also need at least one other member in the chat to share with.
