A recognizable chat makes it easier for your group to find its shared work and read the discussion comfortably. Chat appearance, bubble styles, and display fonts are free on every plan.

## Open Chat Appearance

1. Select the chat's name or avatar at the top of the chat to open its **Settings**. Chat owners can also use **More actions** (**⋯**) → **Settings**.
2. Select **Chat Appearance**.

Chat owners can change the appearance of group chats. In a DM, anyone in the chat can.

Changes are a draft until you select **Save**. Select **Discard** to drop them.

## Title and Description

- **Chat Title** is the name everyone sees.
- **Chat Description** tells people what the chat is for.

## Upload Images

You can upload images to give your chat a unique look:

- **Chat Avatar** – Recommended size: **200 × 200 px**
- **Chat Banner** – Recommended size: **1200 × 400 px**
- **Chat Background** – High-quality wallpaper-style images work best. Use **Upload Background**, or **Generate image** to describe a background and review it before saving.

  <Tip>
    Keep in mind: this will appear differently on desktop and mobile views
  </Tip>

## Customize Background & Opacity

- **Background Opacity:** Adjust from **0–100%**. Higher values show the background image more strongly; lower values fade it so text is easier to read.
- **Use Gradient Overlay:** Add a gradient to make text easier to read and create a polished look. Pick **Color A**, **Color B**, and the **Angle**, then select **Apply Gradient**.

## Choose Bubble Colors

Under **Bubble Colors**, set colors for **Incoming Messages** and **Outgoing Messages**, plus the text colors for bubbles and for names and timestamps. Use **Extract Bubble Colors** to pull colors from your uploaded background for a seamless design.

## Change Your Font

Under **Custom Font (Google Fonts)**, pick a font from **Quick Select Preset Font**, or use any font available on [**Google Fonts**](https://fonts.google.com).

### How to Apply a Custom Font:

1. Visit [fonts.google.com](https://fonts.google.com) and select a font.
2. Open the **Embed** tab and copy the provided **CSS link**.
3. Paste the link into **Google Fonts CSS URL**.
4. Enter the font family name (e.g., `Poppins`) in **Font Family Name**.

   Your new font will now apply to text inside this Chat only.

Use **Remove Font** to go back to the default font.

## Start Over

**Reset appearance** resets background styling, bubble colors, and fonts to their defaults. Your avatar, banner, and background image stay the same, and you can still **Discard** before saving.
