shapes.inc has a live AI engine directory at [shapes.inc/engines](https://shapes.inc/engines). The list changes often, so use that page for the current engines and pricing.

This guide explains what the page means, how to switch engines in a chat, and how to pick an engine without needing to know model IDs.

## Switch engines in a chat

In a DM with a Shape, or in a chat you own, you can change the engine the chat uses:

- In the composer, open **+** → **Engine**. The menu item shows the current engine's name.
- Type `/model` in the composer.
- Open the chat's **Settings** (select the chat's name at the top of the chat) → **Engines**.

**Engines** opens **Choose an AI engine**, with two tabs:

- **Choose engine:** find an engine for the task (see [Find the right engine](#find-the-right-engine)), pick **shapes.inc default** to use each Shape's default engine, and star the engines you use most to keep them in **Favorites**.
- **Engine settings:** set **Reasoning effort** to **Default**, **Off**, **Low**, **Medium**, or **High**. It applies to everyone in the chat, and only the levels the selected engine supports are available. Higher effort can take longer and use more credits. **Temperature** is here too.

The engine built by shapes.inc is shown as **Formless**. Agent chats can also pick **Formless v2.1**; see [Engines in Agent chats](#engines-in-agent-chats).

If you own a Shape, you can set its engine in **Settings** → **Your shapes** → choose the Shape → **AI Engine**. A premium engine uses credits. The same section has the Shape's own **Reasoning effort** setting, which appears for supported engines when **Show internal monologue** is on.

<span id="fallback-engine" />

Shapes no longer have their own **Fallback engine** setting. When a Shape's engine can't reply, for example because its premium engine can't be paid for or the provider fails, the reply comes from the same free engine for every Shape. Free engines don't use credits, and **Generation details** shows why the engine switched. In Agent chats, a premium engine that can't be paid for switches to Formless v2.1 instead; see [Engines in Agent chats](#engines-in-agent-chats).

The current chat interface no longer displays the old thinking panel. **Reasoning effort** changes generation effort; it does not make thinking text visible. The Shape's internal monologue toggle does not restore the old panel either. See [Where did the thinking panel go?](/faq/where-did-the-thinking-panel-go)

<Tip>
  To see which engine wrote a reply, open the ⋯ menu on the Shape's message and select **Generation details**. It shows the engine, why it was picked, how long the reply took, and the credits it used.
</Tip>

## Find the right engine

**Choose engine** ranks engines by what people pick them for:

- **Quick picks:** one tap for **Best overall**, **Best for coding**, **Best for writing**, or **Best free**.
- **Best for:** choose **Coding**, **Writing**, **Math**, **Hard problems**, **Following instructions**, **Long conversations**, **Long prompts**, **Expert questions**, or **Intelligence**. The list keeps only engines rated for that task and ranks them by that rating. A task appears only when some engine has a rating for it.
- **The table:** compare **Score**, **Ratings** (thumbs on replies from that engine), **Cost per reply**, and **Released**. Select a column header, or **Sort** on a phone, to reorder the list. Select a row to use that engine.
- **Free** and **Premium:** show only engines that don't use credits, or only premium ones.
- **Filters:** narrow the list to **Favorites**, **Recommended**, **Intelligent**, or **Immersive**, or to engines marked **Understands images**, **Thinks before replying**, **Can take actions**, or **128K+ context**. You can pick a provider too. Each option shows how many engines it leaves, and **Clear** resets everything.

Task ratings come from LMArena's public leaderboard (CC BY 4.0), and **Intelligence** scores from Artificial Analysis. The line under the table says which one you're looking at. A rating describes the engine in general, so still try your own task before settling on one.

## Engines in Agent chats

Agent chats offer a shorter list of engines, chosen for following loose instructions, multi-step work, and reasoning through vague requests at a sensible cost. Chat mode still offers the full catalog.

- **Formless v2.1** is the free shapes.inc engine for Agent chats. Pick it in the chat's **Settings** → **Engines**, and replies don't use credits, whatever your balance. It is only offered in Agent chats; if the chat switches to Chat mode, the Shape's own engine replies and the pick comes back when the chat returns to Agent.
- **If a saved engine isn't on the Agent list**, the Agent chat replies on a free engine from the list when the saved one was free, or on its default engine when the saved one was premium. The picker shows **shapes.inc default** selected, and **Current AI engine** names the engine that will reply. The saved engine is kept for Chat mode.
- **Gemma 4 31B isn't on the Agent list.** It's still free in Chat mode, and an Agent chat saved on it replies on MiMo-V2.6-Flash. See [why you can't pick it in an Agent chat](/faq/why-cant-i-pick-gemma-in-an-agent-chat).
- **If the sender can't pay for the chat's engine**, the reply continues on Formless v2.1 instead of stopping, and isn't charged. Anyone who can pay still gets the chosen engine. **Generation details** shows the switch.
- **With fewer than 100 credits** and no engine picked for the chat, Agent replies start on Formless v2.1. See [When you run out](/credits#when-you-run-out).

Formless v2.1 has a daily limit across shapes.inc. Past it, replies use another free engine, such as **Formless**, and still don't use credits.

## Automatic upgrades

**Auto upgrade**, under **Settings** → **Personalization** → **Credits**, automatically upgrades you to the best engine shapes.inc recommends. Premium engines use credits. To keep a chat from spending your credits, see [stopping new chats from using your credits](/faq/how-do-i-stop-shapes-in-new-chats-from-consuming-my-credits).

## What You See on the Engines Page

At the top, you will see totals like:

- **AI Engines:** how many models are listed.
- **Providers:** how many model families or companies are available.
- **Always Free:** how many engines are free to use on shapes.inc.

Below that, you can search for an engine, provider, or capability. You can also filter by:

- **All:** shows every listed engine.
- **Free:** shows engines that do not use credits.
- **All families:** lets you filter by provider or model family.

Each engine card shows the provider, how new the engine is, the engine name, and badges like **Premium**, **Free on shapes.inc**, **Reasoning**, **Native Vision**, **Tools**, **New**, or **Unstable**.

## What the Badges Mean

- **Free on shapes.inc:** you can use it without Shape Credits.
- **Premium:** uses Shape Credits unless the chat has sponsored premium access. Premium engine replies are charged at twice the engine's provider cost.
- **Reasoning:** better for careful thinking, coding, planning, and hard questions.
- **Native Vision:** can understand images when the chat supports image input.
- **Tools:** can use supported skills and actions on shapes.inc.
- **New:** recently added to the catalog.
- **Unstable:** failing or temporarily unavailable. Choose another engine until it recovers. See [the Unstable label](/faq/what-does-it-mean-if-an-engine-is-labelled-unstable).

## Common engine questions

### Why did a free engine change to Upgrade to unlock?

An AI Engine is free while its provider's price stays under a limit shapes.inc sets, so a price change can move it to Premium. A short list of engines is always Premium, whatever the price. If an engine you use changes, pick another one under the **Free** filter.

### Why did an engine disappear from the list?

AI Engines can leave the list when they're retired. A shape set to a retired engine then replies on a replacement. **Generation details** on a reply shows which engine wrote it.

### Can I use my own API key for an engine?

No. Shapes run on AI Engines from the shapes.inc catalog, and premium engines use credits.

### How do I make replies faster?

No setting makes an engine write faster. Higher **Reasoning effort** can take longer, so try **Low** or **Off** in the chat's **Settings** → **Engines** → **Engine settings**. To see text as it's written, turn on **Streaming** in **Settings** → **General** → **More preferences**. **Generation details** shows how long a reply took, so you can compare engines.

## Choose for the group's task

Start with the work you want the assistant to do. In the chat's **Engines** page, pick that task under **Best for**, or use the live catalog's descriptions and capability badges to narrow your options, then try the same small task with your candidates.

- **Compare options or plan:** ask the Shape to explain tradeoffs using everyone's constraints. Check whether it distinguishes facts, preferences, and unanswered questions.
- **Draft or study together:** provide the group's brief or study material. Check clarity, accuracy, and how well the response follows your instructions.
- **Use external actions:** look for **Tools** support, then check that the required [skills](/shapeskills) are enabled and configured.
- **Discuss images:** look for **Native Vision** and verify that the chat supports the image input you need.
- **Control costs:** use the **Free** filter or review premium credit requirements. Other features, such as image generation, voice, or higher **Reasoning effort**, can have their own costs.

A model family name alone does not tell you which capabilities a particular engine supports. Availability, pricing, and behavior change, so use the current catalog rather than a fixed ranking.

## Quick Picks

For a first chat, start from **Quick picks** on the chat's **Engines** page, or choose a stable engine with the capabilities your task requires. Keep the instructions and example task the same when comparing engines so the group can judge the results.

If something goes wrong:

- Check the [Unstable label](/faq/what-does-it-mean-if-an-engine-is-labelled-unstable) if an engine is failing or unavailable.
- Review [skills setup](/shapeskills) if an expected action does not run.
- Review [memory](/memory) and [context windows](/contextwindows) if the assistant is missing earlier information.
- Check [unexpected credit usage](/faq/why-is-a-free-engine-costing-credits) before assuming every feature is free with a free text engine.

## A Few Naming Hints

- **Instruct:** built to follow instructions.
- **Vision / VL / V:** related to image understanding.
- **Preview / Latest:** can change more often.

You do not need to memorize these. Open the engine page, read its current description, and try a representative task in your chat.
