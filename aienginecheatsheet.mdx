Shapes, Inc. has a live AI engine directory at [shapes.inc/engines](https://shapes.inc/engines). The list changes often, so use that page for the current engines.

This guide explains what the page means and how to pick an engine without needing to know model IDs.

## What You See on the Engines Page

At the top, you will see totals like:

- **AI Engines:** how many models are listed.
- **Providers:** how many model families or companies are available.
- **Always Free:** how many engines are free to use on Shapes, Inc.

Below that, you can search for an engine, provider, or capability. You can also filter by:

- **All:** shows every listed engine.
- **Free:** shows engines that do not use credits.
- **All families:** lets you filter by provider or model family.

Each engine card shows the provider, how new the engine is, the engine name, and badges like **Premium**, **Free on Shapes.inc**, **Reasoning**, **Native Vision**, **Tools**, **New**, or **Unstable**.

## What the Badges Mean

- **Free on Shapes.inc:** you can use it without Shape Credits.
- **Premium:** uses Shape Credits unless the chat has sponsored premium access.
- **Reasoning:** better for careful thinking, coding, planning, and hard questions.
- **Native Vision:** can understand images when the chat supports image input.
- **Tools:** can use supported skills and actions on Shapes, Inc.
- **New:** recently added to the catalog.
- **Unstable:** may fail, change, or behave less reliably. Avoid using unstable engines as your main engine unless you are experimenting.

## Choose for the group's task

Start with the work you want the assistant to do. Use the live catalog's descriptions and capability badges to narrow your options, then try the same small task with your candidates.

- **Compare options or plan:** ask the Shape to explain tradeoffs using everyone's constraints. Check whether it distinguishes facts, preferences, and unanswered questions.
- **Draft or study together:** provide the group's brief or study material. Check clarity, accuracy, and how well the response follows your instructions.
- **Use external actions:** look for **Tools** support, then check that the required [skills](/shapeskills) are enabled and configured.
- **Discuss images:** look for **Native Vision** and verify that the chat supports the image input you need.
- **Control costs:** use the **Free** filter or review premium credit requirements. Other features, such as image generation or voice, can have their own costs.

A model family name alone does not tell you which capabilities a particular engine supports. Availability, pricing, and behavior change, so use the current catalog rather than a fixed ranking.

## Quick Picks

For a first chat, choose a stable engine with the capabilities your task requires. Keep the instructions and example task the same when comparing engines so the group can judge the results.

If something goes wrong:

- Check the [Unstable label](/faq/what-does-it-mean-if-an-engine-is-labelled-unstable) if an engine is failing or unavailable.
- Review [skills setup](/shapeskills) if an expected action does not run.
- Review [memory](/memory) and [context windows](/contextwindows) if the assistant is missing earlier information.
- Check [unexpected credit usage](/faq/why-is-a-free-engine-costing-credits) before assuming every feature is free with a free text engine.

## A Few Naming Hints

- **Instruct:** built to follow instructions.
- **Vision / VL / V:** related to image understanding.
- **Preview / Latest:** can change more often.

You do not need to memorize these. Open the engine page, read its current description, and try a representative task in your chat.
