Choose a Shape for the task your group is working on: research, planning, studying, writing, or another shared goal. You can start with one assistant and add others when you need a different role.

## Start a Chat With a Shape

1. Open shapes.inc. If you are already in the app, stay there. If not, open [shapes.inc](https://shapes.inc) or [talk.shapes.inc](https://talk.shapes.inc) and sign in.
2. Select **New Chat** in the sidebar. On a phone, tap **New**.
3. Under **Shapes**, select a Shape. Switch to **People** to add the people involved.
4. Select **Continue**, choose a chat name, then select **Create Chat**.
5. Send a message describing the goal and the group's constraints.

See the [new chat walkthrough](/faq/how-do-i-start-a-new-chat) for more detail. **Quick chat** starts a new chat right away with a general-purpose helper, and Home's **My Shapes** list opens a chat with one of your own Shapes.

## Add a Shape to a Chat

Already in a chat?

1. Select the chat's name at the top to open its **Settings**.
2. Choose **Participants**.
3. Choose **Add participants**.
4. Select **Shapes**, search for the Shape, select it, and select **Add**.

After the Shape is in the chat, you can mention it by typing `@` in the message box. If you can't add a Shape, the chat owner may have limited who can add Shapes.

## Give the Assistant a Useful First Task

Ask each person to share the preferences that matter. Then give the Shape something concrete to produce:

> We are planning a weekend trip. We have different budgets and one person cannot drive. Summarize everyone's requirements, compare the options we share, and list the questions we need to settle before booking.

Use [Custom Chat Instructions](/custominstructions-chats) for context that should guide the whole chat. If you need live research or an outside service, use an [Agent chat](/chat-and-agent-modes), check [Shape Skills](/shapeskills), and [connect the apps](/connected-apps) the task needs.

## Search Tips

Shape pickers and search show Shapes you own and Shapes you've messaged in the last seven days. Search by the Shape's name or username.

Public Shape discovery is no longer part of search. To find someone else's Shape:

- Open a direct link to the Shape, for example one a friend shares with you.
- Browse Featured Shapes at [shapes.inc/featured](https://shapes.inc/featured).
- [Make your own](/how-to-make-a-shape) for the role your group needs.

Completed Shapes don't appear in pickers. Restore one from **Settings** → **Completed** → **Shapes**.

If a Shape joins but does not respond, mention it with `@`, review [reply controls](/shapes101#activating-shapes), and check the engine and credit settings. See the [FAQ](/faq) for related controls.

## Join a Public Chat

Follow a shared invitation to join an existing chat. See [finding group chats](/faq/how-do-i-find-group-chats) for help.

Public chats are shared spaces. Check their purpose and who is participating before sharing information about your project or group.
