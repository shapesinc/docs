<a id="why-shape-skills" />

Skills help a Shape turn a group's conversation into useful work: research an option, make a visual, check a calculation, or prepare something everyone can review. Start with the group's goal and describe the result you need.

Built-in skills are included automatically; in Agent chats they can't be turned off, and in Chat chats owners can turn them on or off. Connections to outside services are separate: you can connect apps to your own account, [share supported work apps with a chat](/connected-apps#share-an-app-with-a-chat), or have a chat owner add an MCP server. A shared app uses a separate connection from your personal sign-in.

## Find Skills in Your Chat

<a id="getting-started-with-skills" />
<a id="1-enabling-shape-skills" />

1. Open the chat you want to use.
2. Select the chat's name or avatar at the top to open its **Settings**. Chat owners can also use **More actions** → **Settings**.
3. Select **AI settings**. It's available to chat owners and in DMs with a Shape.
4. Scroll to **Skills** to see the available capabilities.

What you can change depends on the kind of chat (see [Chat and Agent modes](/chat-and-agent-modes)):

- **Agent chats:** the Skills section says these skills are included automatically and can't be disabled. Its **Enabled** and **Disabled** indicators are read-only; you do not need to turn on a master switch before asking a Shape to help.
- **Chat chats:** the chat owner can set skills to **Enabled** or **Disabled** for the chat and turn individual skills on or off. Custom MCP skills are under **Advanced** → **Custom Skills**.

Use the list in your chat to check what is available. For example, it includes **Web Crawl**, **Image Generator**, **Run Code**, **Chat History**, **Total Recall**, and **Voice Gen**.

If you cannot see these settings, ask a chat owner to check them with you. Owners manage the chat's MCP servers.

## Ask for the Result You Need

<a id="3-triggering-skills-in-chat" />

Describe the task in a normal message. Include the shared goal, relevant links or files, constraints, and the format you want back.

For example:

> Compare these three desks for our apartment. Maya will check the measurements, and Drew will check delivery. We need space for two monitors, a width under 120 cm, and a total price under \$400. Read the product pages, list the tradeoffs, and tell us which details are missing.

A useful request makes clear what the group wants to decide and what each person is contributing. The shape's comparison appears in the chat, where Maya can correct a measurement and Drew can add delivery information. Ask the shape to update the recommendation using those replies, then decide together. Researching a product does not buy it.

A Shape chooses which skills to use for the task. Naming a skill can clarify your request, but it does not guarantee that an outside service will be connected or that the action will succeed.

Use [custom instructions](/custominstructions-chats) for standing preferences, such as the group's budget or preferred summary format.

## What You Can Work on Together

<a id="4-built-in-skills" />
<a id="skill-ideas" />

### Research Options

**Web Crawl** and **Browser** can support work with web sources. Give the Shape the pages or research question you want it to investigate.

> Read these two venue pages and compare accessibility, capacity, and cancellation terms. Link to the details you used and flag anything we should confirm with the venue.

Check the returned sources before making a decision. A page may be unavailable, require sign-in, or omit the detail you need.

One friend can contribute the venue links while others add accessibility needs or travel constraints. The shape brings that information into a shared comparison; ask for a [poll or shortlist](/multiplayer-activities) when the group is ready to choose. Reading public pages does not require every participant to connect an account. Private sources need the relevant access.

### Create and Discuss Images

**Image Generator** and **Image Annotation** support visual work. Explain the purpose of the image, the audience, and the details the group has already agreed on.

> Make a draft poster for our neighborhood cleanup using the date and meeting point we agreed. Maya will check the wording, and Drew will check that the location is clear. Post the draft here for us to review.

The group can reply with corrections and ask for a revised image in the same conversation. Review generated text and details before downloading or sharing the result; generating the poster does not post it elsewhere. See the [image generation guide](/articles/best-ai-image-generators-2026) for related guidance.

### Check Calculations and Work With Code

**Run Code** supports tasks that benefit from calculations or code. **Code Projects**, **Claude Code**, and **Codex** also appear in the Skills list for coding work.

Hosted Claude Code and Codex share **up to 2 free coding starts per day**, subject to separate model-token and computer allowances. Run Code and Browser also use the shared computer allowance. See [free coding-agent limits and paid usage](/faq/how-do-free-coding-agent-limits-work) before planning work around the free allowance.

> Use this costs file to compare three budgets for our weekend away. Maya will confirm transport costs, and Drew will confirm accommodation. Show the totals and assumptions here so we can check them together.

Check the inputs, totals, and any missing costs in the returned result. A calculation in the chat does not update the source spreadsheet unless you also request and complete a supported edit.

For a coding task, one teammate can describe the bug, another can supply the expected behavior, and the shape can help investigate or make a requested change. Ask it to report what changed, which checks ran, and where to review the output. A started coding run is not a completed fix, and a local edit is not a published branch or pull request. Access to a repository or outside service may require a connection.

In Agent chats, **AI settings** also has **Code Projects** for connecting GitHub repositories to code tasks in the chat. New projects are private; you can share one with the chat after creating it. To let Shapes hand work to Codex or Claude Code on your own machine, see [Connect your computer](/connect-your-computer).

### Review Shared Context

<a id="total-recall" />
<a id="total-recall-skills" />

**Chat History** and **Total Recall** help with earlier conversation context. Ask for the specific decision, requirement, or discussion you need to revisit.

> Maya has just joined our trip chat. Summarize the dates and budget we agreed here, separate confirmed decisions from open ideas, and point out where we still need her input.

The recap appears in the chat, so existing members can correct it and Maya can contribute without one person relaying the conversation. Check the summary with the people involved. For earlier-chat access and reviewing or correcting remembered information, see [Memory](/memory).

### Prepare Files and Voice Content

**File Generator**, **File From URL**, and **Voice Gen** are available in the Skills list. Describe the document, source file, or spoken result you want to work with.

> Turn our agreed plan into a file we can share, with the decisions first and the remaining questions underneath.

Specify the format you need and check that the returned file opens correctly. For voice settings and calls, see [Voice Calls](/voicecalls).

For example, the person organizing a meetup can ask for a downloadable plan after everyone has checked the time and place. The shape prepares the file in its reply; a group member opens it, checks the details, and shares it where needed. Creating a file or spoken clip does not send it to an outside recipient.

You can also share a public Google Docs, Sheets, Slides, or Drive link, and Shapes can read it. See [Connected apps](/connected-apps).

### Plan Follow-up Work

**Scheduled Actions** is listed for scheduled work. Include the task, intended time, and time zone when asking for a follow-up.

> Remind this chat tomorrow at 6 p.m. Pacific time to confirm everyone's travel dates.

Check the Shape's result to see whether an action was actually scheduled. A suggested reminder in a reply is not a scheduling confirmation. Scheduled reminders and in-progress work appear in **Settings** → **Tasks**, where you can cancel them. See [Tasks](/tasks).

## Connect an Outside Service

<a id="2-adding-custom-mcp-skills" />

There are three ways to give Shapes access to another service:

- **Connected apps:** connect apps such as Gmail, Google Calendar, Notion, or Google Drive to your account in **Settings** → **Connected apps**, or from the composer's **+** menu → **Connected apps**. When a Shape needs an app you haven't connected, a Connect card appears in the chat. See [Connected apps](/connected-apps).
- **Apps found by an Agent chat:** Agent chats can find more apps in the public MCP directory and WebMCP. A Connect card appears in the chat, and the task continues after you connect.
- **An MCP server added to the chat:** a chat owner adds the server's details, as described below. You need the server details from that service or its administrator.

Mentioning an app or pasting a private document link does not connect an account. A connected app or server supplies the actions it supports; access still depends on the service and the member who is signed in.

### Add an MCP Server

Chat owners can add servers in Agent chats:

1. Open the chat's **Settings** → **AI settings**.
2. Find **MCP servers**, below **Skills**.
3. Select **Add MCP server**.
4. Enter a descriptive **Name** so the group can recognize the connection.
5. Check **Transport**. The dialog defaults to **Streamable HTTP**; use the transport required by the server provider.
6. Enter the provider's endpoint in **Server URL**.
7. Review **Access**. Its default is **No sign-in (public tools)**. Choose **Each member signs in** when everyone should use their own account, or **Shared API key** when everyone in the chat uses one key, as the service requires.
8. Select **Add server**.

Use **Cancel** to close the dialog without adding the server.

In Chat chats, owners add custom MCP skills instead: open **Skills** → **Advanced** → **Custom Skills**, set **MCP skills** to **Enabled**, and use **Add MCP skill**.

The endpoint must be an MCP server URL supplied for this purpose. A service's ordinary website or a link to one document may not be a server endpoint.

### Connect Your Own Account

When the service requires sign-in, each chat member connects their own account through the connection flow. An action uses the account of the member who sent the request.

For example, if you ask the Shape to work with a connected service, your access determines which resources it can use. Another member may need to sign in separately and may have different permissions.

Adding a server to a group chat does not give every member access to the owner's private accounts.

### Try a Small Task

After connecting, start with something easy to check:

> Find the project document I can access in this service and summarize its open questions for our group.

Review which resource the Shape used and whether the result matches your request. For work that changes something in another app, say whether you want a draft or a completed action, and check the returned confirmation.

## Troubleshooting

<a id="5-tips-tricks" />

### I Cannot Enable or Disable a Built-in Skill

In Agent chats, built-in skills are included automatically, and their availability controls are read-only. Use **Skills** to inspect them, then ask the Shape for the task you want completed. In Chat chats, only the chat owner can turn skills on or off.

MCP connections are managed separately under **MCP servers** in Agent chats, or **Advanced** → **Custom Skills** in Chat chats.

### I Cannot Add an MCP Server

Chat owners add MCP servers. Ask an owner to open **AI settings** and check the server setup. If you want to use an app with your own account, connect it in **Settings** → **Connected apps** instead.

If the dialog reports a problem, check the **Server URL**, **Transport**, and **Access** against the provider's instructions. Copy the endpoint intended for MCP connections.

### The Service Asks Me to Sign In

Complete the connection flow with your own account. Another member's sign-in does not connect your account. If a Connect card appears in the chat, only the person who asked can connect their account from it.

If you have already connected, check whether the service needs you to reconnect or whether your account can access the requested resource. **Settings** → **Connected apps** shows apps that need permission or reconnecting.

### The Shape Cannot Find a Document or Perform an Action

Check that the required app is connected or MCP server has been added, that you have connected your account when required, and that your account has permission to use the resource.

Be specific about the document or action. A connection may support only some of the features available on the service's website.

### A Skill Fails or the Result Is Incomplete

Try one small task with a clear input. Review the error or missing information, then check the relevant source or connection.

For web research, try opening the source yourself. For generated files, check the format and contents. For calculations, review the input data and assumptions.

If the problem continues, ask in [Help Me](https://talk.shapes.inc/help). Include what you asked for, the skill involved, and the error message. Keep account credentials out of your support message.
