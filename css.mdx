You can add your own HTML and CSS to a shape's public profile. Custom profile HTML and CSS is free on every plan; only the shape's owners can edit it.

Custom CSS styles the HTML you add below the built-in profile. It does not change the app's navigation, profile header, or other product controls.

## Open page customization

1. Open **Settings** → **Your shapes** and select the shape.
2. Choose **Share** → **Page customization**.
3. Enter the content in **Custom HTML** and its styles in **Custom CSS**.
4. Turn on **Enable custom HTML/CSS on profile page** and select **Save Changes**.
5. Select **View public page** to check the result. Check it on a phone as well as a larger screen.

Each field allows up to **20,000 characters**. Keep a copy of any existing HTML and CSS before replacing it. Custom CSS only appears when custom HTML is enabled and contains supported content.

<span id="1-copy-this-example-css-as-a-base" />

## Start with a small custom section

Paste this into **Custom HTML**:

```html
<section class="profile-card">
  <h2>Study group helper</h2>
  <p>Bring your notes and questions. We can work through them together.</p>
</section>
```

Then paste this into **Custom CSS**:

```css
.profile-card {
  box-sizing: border-box;
  max-width: 100%;
  padding: 24px;
  border: 1px solid var(--border-midway);
  border-radius: 16px;
  background: var(--background-secondary);
  color: var(--body-primary);
}

.profile-card h2 {
  margin: 0 0 12px;
  color: var(--highlight-primary);
}

.profile-card p {
  margin: 0;
  line-height: 1.6;
}
```

Use class names you define in your own HTML. The profile supplies theme variables such as `--background-secondary`, `--body-primary`, `--highlight-primary`, and `--border-midway`, so the section can follow its light or dark theme.

## Adjust and check the result

You can ask a shape to help write or revise the HTML and CSS. Include both snippets so it styles the elements you actually have. Start with one small change, save it, and reopen **View public page** to check it.

- If nothing appears, check that the enable switch is on, the HTML contains supported content, and you saved your changes.
- If styles do not apply, check that the class names in the CSS match the HTML. Rules for `body`, `:root`, or old app-generated class names do not style the built-in profile.
- Scripts, embedded apps, external stylesheets, and CSS resource loading are not supported. Basic HTML and scoped CSS are supported; responsive `@media` and feature-based `@supports` rules can be used.
- Avoid fixed widths that overflow on phones. Keep text readable in light and dark themes.

To hide your custom section, turn off **Enable custom HTML/CSS on profile page** and save. The editor keeps the saved HTML and CSS for later.

## 2. Describe the Look You Want

AI works best when you give it a clear description. You don’t need to know CSS, just explain the _theme_ you’re going for.
