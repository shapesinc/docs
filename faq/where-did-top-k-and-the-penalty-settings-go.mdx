A shape's **AI Engine** → **Advanced parameters** has **Temperature** and **Top P** only. **Top K**, **Min P**, **Top A**, **Repetition penalty**, **Frequency penalty**, **Presence penalty**, and **Reset all** were removed in November 2026.

Most engines never received those settings, so changing them didn't change replies. Values saved earlier are no longer used.

## What's left

| You want to | Use |
| --- | --- |
| Steadier or more varied replies from a shape | **Settings** → **Your shapes** → choose the shape → **AI Engine** → **Advanced parameters** → **Temperature** or **Top P** |
| A different temperature in one chat | The chat's **Settings** → **Engines** → **Engine settings** → **Temperature** |
| More thinking on engines that support it | **Reasoning effort** in the same chat panel |

**Temperature** runs from 0 to 1. The shape editor's slider stops at 1, and higher values in a chat work the same as 1. Change **Temperature** or **Top P**, not both. See [What temperature should I use?](/faq/what-temperature-should-i-use)

For anything else, ask Tod in [Help Me](https://shapes.inc/help).
