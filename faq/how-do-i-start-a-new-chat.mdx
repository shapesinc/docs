Select **New chat**, choose who's in it, and select **Create Chat**. Use a chat for something you want to do together, such as planning a trip or working through a project. You do not need to create a shape first.

## Start a new chat

1. Select **New chat** at the top of the sidebar. On a phone, tap **New** in the bottom tabs.

2. The picker opens on **People**. Select the people to include, or open **Shapes** to choose **Auto** or an existing shape. To start on your own, select **Auto** without adding people. Then select **Continue**.

3. In **Chat details**, give the chat a name if you want to change the suggested one, then select **Create Chat**.

Your chat is ready to use. Select **Invite** at the top of the chat to share a link with anyone else who should join.

## Invite more people

- Select **Invite** at the top of the chat, then select **Share** or tap the link to copy it.
- On a phone, iPad, or Mac, enter a **Phone number** in the same dialog and select **Text**.
- To add people or shapes directly, select the chat's name to open its **Settings**, then choose **Participants** → **Add participants**.

## Start another chat with the same shape

A shape's **Chat** button opens your existing chat with it. To start a separate one, select **New chat**, open **Shapes**, select the shape without adding people, then select **Continue** and **Create Chat**.

Adding people to a chat doesn't create a new chat: they join the one you're in.

## Other ways to start

- Type in the composer on Home (**Start here…**) to start a chat. The shape chip shows **Auto** until you pick a shape.
- Inside a chat, open **More actions** → **New chat**. Choose participants, select **Next**, fill in **Chat details**, and select **Create Chat**.
- On a computer, press ⌘/Ctrl+Shift+O.
- On Home, select **Invite** under **Invite friends to this chat**. The invite dialog opens with a link to share, and inviting someone from Home takes you into the new chat.

There's no chat mode to choose: every chat can search the web and take actions, and a shape replies in its own voice when you're just chatting with it. The **Auto** choice in the shape picker is about which shape joins. See [How chats work](/chat-and-agent-modes).

## How many shapes can a chat have?

A chat can hold up to 1,000 shapes.

## Can I choose my own invite link?

No. Each chat gets its own invite link, and you can't edit it. Use the chat's title and description to show what the group is for.

For anything else, ask Tod in [Help Me](https://talk.shapes.inc/help).
