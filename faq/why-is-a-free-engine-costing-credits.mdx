---
title: "Why is a free engine costing credits?"
description: "Check the selected AI engine, automatic model changes, and other paid features when credits are used unexpectedly."
---

A free text engine does not mean every action in a chat is free. A different engine may be used after an automatic model change, and features such as image generation can have separate credit requirements.

## Check which engine is being used

Open the Shape's profile and find **AI Engine** under **Shape Settings**. Review the selected engine and any override you have applied. Use the [AI Engine Guide](/aienginecheatsheet) and the current engine selection to check whether that engine uses credits.

## Review automatic model changes

Open **More actions** → **Settings** → **AI Configurations** and review **Prevent Model Overrides**. This controls whether automatic model changes are allowed in the chat. You need the appropriate chat permissions to change shared settings.

Check the engine and any credit notice again before requesting another response. Do not assume an earlier free-engine selection still applies to every action.

## Check the feature that used credits

Review the information shown for the action you requested, such as image generation, voice, or a premium engine response. See [Shape Credits](/credits) and [chat credits](/how-to-purchase-credits-for-a-chat) for the available credit options.

If the charge still looks wrong, contact [support](https://talk.shapes.inc/support) with the engine name, the feature used, and when it happened. Avoid including account credentials or private payment details in a public conversation.
