Every chat offers a short list of engines. Chat mode, which offered the full catalog, has been removed along with Agent and Auto modes; see [How chats work](/chat-and-agent-modes).

The list keeps engines with evidence that they follow loose instructions and finish long, multi-step work at a sensible cost. An engine on the list also has to pass its automatic check for actions, so the count moves between 16 and 18 while an engine waits for that check.

## Engines in chats

The list in November 2026:

| Free | Premium |
|---|---|
| **Formless v2.1** | Claude Opus 5.5, Claude Sonnet 5.5, Claude Haiku 5.5, Claude Fable 5.2 |
| **Formless** | GPT-6 Astra, GPT-6.1 Sol, GPT-6.1 Terra, GPT-6 Luna |
| **MiMo-V2.6-Flash** | Gemini 4 Argon, Kimi K3.1 Pro, GLM 5.3 |
| **Ling 3.1 Flash** | DeepSeek V4.1 Flash 1017, MiMo-V2.6-Pro, MiniMax M3.1 Flash |

- **Formless v2.1** is the free shapes.inc engine. Replies on it don't use credits, whatever your balance. It has a daily limit across shapes.inc; past it, replies move to another free engine.
- An engine is free while its provider's price stays under the limit shapes.inc sets, so an engine can move between columns. The **Free** filter in **Choose an AI engine** always shows the current free engines.
- When a family releases a newer version that passes the same checks, it replaces the older one on the list.

## The best free engine

**Formless v2.1**. Pick it in the chat's **Settings** → **Engines**.

## A shape set to an engine that isn't on the list

A shape's own **AI Engine** (under **Settings** → **Your shapes**) isn't used for ordinary replies. The reply comes from, in order:

1. The engine picked for the chat in its **Settings** → **Engines**.
2. The chat owner's pick for new chats, as it was when the chat started.
3. The shapes.inc default: a premium engine when you have 100 or more credits, **Formless v2.1** below that.

A chat saved on an engine that left the list replies on **MiMo-V2.6-Flash** when the saved engine was free, or on the shapes.inc default when it was premium.

When you play a scene with a shape, its in-character reply can use the shape's own engine, as Chat mode did.

## Use an engine that isn't on the list

Engines outside the list can't be picked for a chat. Switching a chat to Chat mode used to bring back the full catalog; that option is gone with the modes. See [Engines in chats](/aienginecheatsheet#engines-in-agent-chats).
