---
title: "How do I cancel a reminder?"
description: "Cancel a reminder, recurring task, or watch a shape set up for you."
---

Open **Settings** → **Tasks** and select **Cancel** next to the reminder. Recurring tasks, watches, and work shapes are doing for you are listed there too.

## Cancel it in Settings

1. Open **Settings** and select **Tasks**.
2. Find the reminder under **Scheduled**. Work a shape is still doing is under **In progress**, and watches show **Watching for updates**.
3. Select **Cancel** next to it.

Each item shows its title, the chat it belongs to, and when it runs next or how often it repeats. Select the chat's name to open it.

To stop a repeating reminder for a while without losing it, select **Pause** instead. It shows **· Paused** until you select **Resume**. Watches can only be cancelled. See [Pause a routine](/tasks#pause-a-routine).

<span id="or-ask-in-the-chat" />

## Ask in the chat

Ask the shape in the chat where you set it up: "Cancel the Friday reminder" or "Pause my weekday reminder." Check **Settings** → **Tasks** afterward to make sure it's gone.

If **Tasks** is empty, nothing is scheduled or running for you. Chats in **Archive** pause their watches and scheduled checks until you unarchive them.

See [Tasks](/tasks) for more about reminders and watches.

For anything else, ask Tod in [Help Me](https://talk.shapes.inc/help).
