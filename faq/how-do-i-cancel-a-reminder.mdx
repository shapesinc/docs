---
title: "How do I cancel a reminder?"
description: "Cancel a reminder, recurring task, or watch a Shape set up for you."
---

Reminders, recurring tasks, and work Shapes are doing for you are all listed in one place.

## Cancel it in Settings

1. Open **Settings** and select **Tasks**.
2. Find the reminder under **Scheduled**. Work a Shape is still doing is under **In progress**, and watches show **Watching for updates**.
3. Select **Cancel** next to it.

Each item shows its title, the chat it belongs to, and when it runs next or how often it repeats. Select the chat's name to open it.

## Or ask in the chat

You can also ask the Shape in the chat where you set it up, for example "Cancel the Friday reminder." Check **Settings** → **Tasks** afterward to make sure it's gone.

If **Tasks** is empty, nothing is scheduled or running for you. Chats in **Completed** pause their watches and scheduled checks until you reopen them.

See [Tasks](/tasks) for more about reminders and watches.
