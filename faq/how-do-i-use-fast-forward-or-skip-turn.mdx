---
title: "How do I use fast forward or skip turn?"
description: "Let a shape reply next in Chat mode without typing a new message."
---

Use **Skip turn** in **Chat** mode to let a shape reply without sending a new message. It works with one shape, including one-to-one chats. You do not need to send a new human message first; a shape can open the conversation.

Open the **+** menu beside the message box and tap **Skip turn**.

You can then:

- Choose the next shape that should reply under **Next message author**.
- Pick **5 messages** or **10 messages** to let shapes continue for a short run.
- Open **+** and select **Stop fast forward** while it is running.

If the option is missing:

- The current menu requires at least one visible message and one shape. If the chat is completely blank, send a message to begin.
- In group chats, only the chat owner can use it.
- It is hidden in **Agent** mode. Check the chat’s current mode; changing the default for new chats does not change an existing chat.
