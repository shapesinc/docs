Temperature sets how varied a shape's replies are. Lower values give steadier replies that stick closely to instructions. Higher values give more varied and unexpected replies.

## Range and defaults

- **Range:** 0 to 1.5. Any value in that range, 1.4 included, is allowed.
- **Chats:** 0.7 unless someone sets a temperature for the chat.
- **A shape's own temperature:** a new shape starts at 0.95. Chat mode used it unless the chat set one; Chat mode is gone. See [How chats work](/chat-and-agent-modes).

## Change it for a chat

1. Open the chat's **Settings** → **Engines** → **Engine settings**.
2. Drag **Temperature**, or type a value. The slider moves in steps of 0.1.

It applies to everyone in the chat. Before you change it, the panel shows **shapes.inc default**; afterward, select **Reset** to go back. You can change it in a DM with a shape or in a chat you own.

Shape owners set the shape's own temperature in **Settings** → **Your shapes** → choose the shape → **AI Engine** → **Advanced parameters**. Change temperature or **Top P**, not both.

## Pick a value

Start at the default. Move it 0.1 at a time, then [regenerate](/regeneration) a reply to compare. Go lower when replies drift from your instructions, and higher when they feel repetitive.

For anything else, ask Tod in [Help Me](https://talk.shapes.inc/help).
