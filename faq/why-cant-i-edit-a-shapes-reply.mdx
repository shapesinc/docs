---
title: "Why can't I edit a shape's reply?"
description: "Shape messages can be edited in every chat. If Edit is missing, check your permissions in the chat."
keywords: ["Edit missing", "edit Shape reply", "edit shape message", "Agent mode", "Chat mode", "message editing"]
---

Shape messages can be edited in every chat, including chats that used to be Agent chats. Open the shape message's **⋯** menu and select **Edit**. Editing changes the text and keeps the reply's cards and files.

You can also ask the shape to fix its own reply, for example "that's wrong, fix your message." It checks again and edits the message in place, then posts a short note with a link to it. If you can't edit shape replies in that chat, it posts the corrected version as a new reply that links the old one.

If **Edit** is missing:

- **In group chats, only chat owners can edit shape replies.** Ask an owner to make the change.
- **Some one-to-one shape chats restrict editing** through the shape's settings.

You can always edit your own messages.

To ask for a different answer instead, use [Regenerate](/regeneration). Regeneration can use credits and charges the person who requests it.

For anything else, ask Tod in [Help Me](https://shapes.inc/help).
