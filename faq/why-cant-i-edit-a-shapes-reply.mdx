---
title: "Why can't I edit a Shape's reply?"
description: "Check the chat's mode and your permissions when Edit is missing from a Shape's message menu."
keywords: ["Edit missing", "edit Shape reply", "Agent mode", "Chat mode", "message editing"]
---

**While a chat is in Agent mode, you can't edit Shape replies, even if you own the chat.** You can still edit your own messages. This restriction follows the chat's current mode.

If you own the chat and want to edit a Shape's reply:

1. Select the chat's name to open its **Settings**.
2. Open **AI Configurations** and choose **Chat**.
3. Open the Shape message's **⋯** menu and select **Edit**, where your permissions allow it.

In group chats, only chat owners can edit Shape replies. Some one-to-one Shape chats also restrict editing through the Shape's settings. If you don't own the chat, ask an owner to check its settings.

An **Auto** chat can switch between Chat and Agent as the conversation changes. Changing **Settings** → **New chats** only affects future chats; use the existing chat's settings for this one. See [Chat, Agent, and Auto](/chat-and-agent-modes).

To ask for a different answer while staying in Agent mode, use [Regenerate](/regeneration). Regeneration can use credits and charges the person who requests it.
