---
title: "Does shapes.inc support Markdown?"
description: "See the Markdown supported by shapes.inc, including tables, task lists, and math."
keywords: ["Markdown", "formatting", "tables", "task lists", "math", "LaTeX", "KaTeX", "code blocks"]
---

Yes. shapes.inc renders Markdown in messages, including tables, task lists, and math:

| Markdown                      | Output                |
| :---------------------------- | :-------------------- |
| `**bold**`                    | **bold**              |
| `*italic*`                    | _italic_              |
| `***bold and italic***`       | **_bold and italic_** |
| `~~strike~~`                  | ~~strike~~            |
| `# Heading `                  | # Heading             |
| `## Heading`                  | ## Heading            |
| `### Heading `                | ### Heading           |
| `> quote`                     | \> quote              |
| `inline code`                 | `inline code`         |
| \`\`\`code\`\`\`              | `code block`          |
| `- item`                      | - item                |
| `1. item`                     | 1. item               |
| `[link](https://example.com)` | link                  |
| `- [ ] task`                  | a task list checkbox  |
| `\| a \| b \|` table rows       | a table               |
| `$x^2$` or `\(x^2\)`           | inline math           |
| `$$x^2$$` or `\[x^2\]`         | block math            |

For anything else, ask Tod in [Help Me](https://shapes.inc/help).
