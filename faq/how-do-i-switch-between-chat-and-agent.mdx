---
title: "How do I switch between Chat and Agent?"
description: "Set how new chats start, or change the mode of a chat you own."
---

Every chat is a **Chat** chat (just talking), an **Agent** chat (Shapes can search the web, run code, and take other actions for you), or **Auto**, which picks Chat or Agent for each message based on what you need.

## Set how new chats start

1. Open **Settings**.
2. Under **New chats**, choose **Auto**, **Chat**, or **Agent**.

**Auto** is the default. This only changes chats you start from now on; existing chats keep their mode.

## Change one chat

If you own the chat:

1. Select the chat's name at the top, or choose **More actions** (⋯) → **Settings**.
2. Open **AI Configurations**.
3. Choose **Auto**, **Chat**, or **Agent**.

A chat set to **Auto** can switch between Chat and Agent from one message to the next. A chat you set to **Chat** or **Agent** stays that way until you change it.

If you don't see these options, ask the chat's owner to change it. The mode can't be changed in DMs with other people.

See [Chat, Agent, and Auto](/chat-and-agent-modes) for what each mode does.
