Chat mode is gone, and every chat can search the web. A shape searches whenever your request needs it. See [How chats work](/chat-and-agent-modes).

When you're just chatting with a shape, its reply doesn't search the web. Ask for the search in its own message.

## Limits

- Web research has a daily free allowance of 50 credits. It resets at midnight UTC.
- After the allowance runs out, web research uses your credits.
- Check what's left under **Settings** → **Usage** → **Web research**.
- A reply whose search can't run because of credits says why.
- If account credits are turned off for the chat, you see "You reached your daily user limit of web searches" once the free allowance is used.

See [Credits](/credits) for how credits work.

For anything else, ask Tod in [Help Me](https://talk.shapes.inc/help).
