Only when you ask with `/web`. In Chat mode a shape doesn't search the web on its own. In an [Agent chat](/chat-and-agent-modes), a shape searches whenever your request needs it.

## Search in Chat mode

1. Type `/web` in the composer.
2. Pick which shape answers.
3. Type your search and send. The shape replies using the results.

If the search can't run, the shape still replies, without search results. For searches the shape runs on its own, a chat owner switches the chat to Agent: open the chat's **Settings** → **AI settings** and choose **Agent**. See [Switch an existing chat](/chat-and-agent-modes#switch-an-existing-chat).

## Limits

- Web research has a daily free allowance of 50 credits. It resets at midnight UTC.
- After the allowance runs out, web research uses your credits.
- Check what's left under **Settings** → **Usage** → **Web research**.
- In an Agent chat, a reply whose search can't run because of credits says why.
- If account credits are turned off for the chat, you see "You reached your daily user limit of web searches" once the free allowance is used.

See [Credits](/credits) for how credits work.
