Gemma 4 31B isn't gone. It's still free in Chat mode, but it isn't on the shorter list of engines offered in Agent chats.

Agent chats do long, multi-step work with tools. That list keeps the engines that best understand loose instructions and finish long tasks at a sensible cost, based on benchmarks. See [Engines in Agent chats](/aienginecheatsheet#agent-engines).

## If your chat was using it

If your chat was on Gemma 4 31B in Agent mode, it now replies on MiMo-V2.6-Flash, which is also free.

To stay on Gemma 4 31B, a chat owner can set the chat to **Chat**: open the chat's **Settings** → **AI settings** and choose **Chat**. See [Switch an existing chat](/chat-and-agent-modes#switch-an-existing-chat).

If it isn't replying in Chat mode either, see [what the Unstable label means](/faq/what-does-it-mean-if-an-engine-is-labelled-unstable).
