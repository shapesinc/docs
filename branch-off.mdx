Use **Branch off** when part of a group chat deserves its own space, such as a side question you want to explore without derailing the group's plan.

**Branch off** creates a **new private chat** starting from the message you choose.\
It copies up to the **last 50 messages**, ending with your selected one, so the new chat starts with the right context.

### Why use it

- Keep the main chat focused while you dig into one topic.
- Work through an idea privately, then bring the result back to the group.
- Try a different direction with a Shape without changing the original chat.

### How to use it

1. Open the **⋯** menu on any message.
2. Choose **Branch off**.
3. Select **Confirm**. The new chat is created and opens for you.

Branch off is available in chats, but not in DMs.
