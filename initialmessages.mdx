## **What Are Initial Messages?**

- If you **set an initial message**, your Shape sends that message first when someone new starts talking with it. Automatic participation depends on the chat's reply settings.
- If you **leave it empty**, there's no set greeting. Depending on the chat, the Shape may open with a line of its own or wait for someone to speak first.

This gives creators full control over how a Shape greets users and frames the interaction.

## **Where to Set It**

- **When creating a Shape:** open **Advanced** on **Create a shape** and fill in **Initial message**.
- **For an existing Shape:** open **Settings** → **Your shapes**, select the Shape, choose **Profile**, and open **Personality and behavior**. Edit **initial message**, then select **Save Changes**.

Only the Shape's owners can change it.

## **Why Set an Initial Message?**

A good initial message helps:

- Set the **tone** for the conversation.
- Give users a **sense of your Shape’s personality** right away.
- Provide important **context** for how the user should interact with the Shape.

## **Letting Users Go First**

If you want **the user to provide the first context** in a conversation, you can leave the field empty; it is completely optional.

## **Using Custom Chat Instructions for First Messages**

If no initial message is set by the creator, [**custom chat instructions**](/custominstructions-chats) can be used to drive what the Shape says first.

- Custom chat instructions provide **extra context** that will influence the Shape’s opening message and all messages that follow.
- This is useful if you want to control the opening _per chat_ rather than globally for all chats with the Shape.

## AI replies

Open the chat's **Settings** by selecting its name or avatar at the top of the chat, then go to **AI Configurations** → **AI replies** → **Auto-reply triggers** to review when the Shape can speak without a new prompt. **AI Configurations** is available to chat owners and in DMs with a Shape. An initial message sets the opener; it is separate from these participation controls.

See [assistant behavior](/designing-social-intelligence) for the available triggers. To ask for a reply directly, mention the Shape with `@`.
