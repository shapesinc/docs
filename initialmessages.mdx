<span id="what-are-initial-messages" />

## **What an Initial Message Does**

- If you **set an initial message**, your Shape sends that message first when someone new starts talking with it. Automatic participation depends on the chat's reply settings.
- If you **leave it empty**, there's no set greeting. Depending on the chat, the Shape may open with a line of its own or wait for someone to speak first.

## **Where to Set It**

- **When creating a Shape:** open **Advanced** on **Create a shape** and fill in **Initial message**.
- **For an existing Shape:** open **Settings** → **Your shapes**, select the Shape, choose **Profile**, and find **Greeting**. Edit **First message**, then select **Save**.

Only the Shape's owners can change it.

<span id="why-set-an-initial-message" />

## **When to Set an Initial Message**

An initial message:

- Sets the **tone** for the conversation.
- Gives users a **sense of your Shape’s personality** right away.
- Provides **context** for how the user should interact with the Shape.

## **Letting Users Go First**

To let **the user provide the first context** in a conversation, leave the field empty. It is optional.

## **Using Custom Chat Instructions for First Messages**

When the creator has set no initial message, [**custom chat instructions**](/custominstructions-chats) drive what the Shape says first.

- Custom chat instructions provide **extra context** that influences the Shape’s opening message and all messages that follow.
- Use them to control the opening _per chat_ instead of globally for all chats with the Shape.

<span id="free-will" />

## AI replies

Open the chat's **Settings** by selecting its name or avatar at the top of the chat, then go to **AI settings** → **AI replies** → **Auto-reply triggers** to review when the Shape can speak without a new prompt. **AI settings** is available to chat owners and in DMs with a Shape. An initial message sets the opener; it is separate from these participation controls.

See [assistant behavior](/designing-social-intelligence) for the available triggers. To ask for a reply directly, mention the Shape with `@`.
