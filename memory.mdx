Memory helps a Shape keep track of what your group has shared: decisions, preferences, and details that matter later. Memory is selective, not a perfect record, so check important details and correct anything a Shape gets wrong.

### **How Memory Works**

Shapes use a few kinds of memory:

- **Short-term memory:** the recent conversation in the chat you're in.
- **Long-term memory:** summaries of past conversations that a Shape can bring back up when they're relevant.
- **Saved notes:** things people asked a Shape to remember. A note can be personal, for a chat, or for a workspace.

Short-term memory only covers the chat you're in. Long-term memories and notes can come up in later conversations when they're relevant. In Agent chats, a Shape may also recall memories from other chats you can access, and it finds the right ones more reliably in long histories.

### **Ask a Shape to Remember Something**

Say what you want remembered, for example "Remember that Sam is vegetarian and we're booking for six." The Shape saves it and confirms only once it's saved. Its reply says where the note went: **Personal**, a chat, or a workspace.

You can also type `/remember` followed by the note to save it to the chat's memory.

### **Memory Commands**

Type these in the composer:

| Command | What it does |
| --- | --- |
| `/remember` | Save a note to this chat's memory. |
| `/memory` | Open the memories for this chat. |
| `/compact` | Save this chat to memory so Shapes keep the gist. `/sleep` does the same. |
| `/clear` | Clear this chat's short-term memory. Chat owner only. |
| `/wack` | Reset a Shape's short-term memory. Chat owner only. |
| `/reset` | Reset a Shape's long-term memories from this chat. Chat owner only. |

See [commands and shortcuts](/commands-and-shortcuts) for the full list.

### **Manage Memories**

Open **Settings** → **Manage memories** to see the **Memories** page. From a chat, select **More actions** (⋯) in the chat header → **Manage memories**, open the chat's **Settings** → **Manage memories**, or type `/memory`. **Back to chat** returns you to the conversation.

The **Memories** page has four views:

- **Personal:** notes only you can add, edit, or delete.
- **Chats:** notes for a chat. Pick the chat to see its memories.
- **Workspaces:** notes for a workspace. Pick the workspace to see its memories.
- **Conversation summaries:** the summaries Shapes made from your conversations.

Each view shows whether its memories are **Private** or **Shared**. Use **Add memory** to write a new one, **Edit** or **Delete** on a memory to change or remove it, and **How this memory works** to see where it is used and who can change it. Shared memories can be changed by people allowed to manage them (others see them as view only), and conversation summaries can be viewed and changed by the people included in them.

Deleting a memory doesn't change messages or replies that already used it, and new conversations can create new memories.

<Info>
  Replies can include remembered information, and anyone who can read the conversation can read those replies, including people invited later.
</Info>

### **Types of Conversations**

- **Chats:** chats you can invite more people and Shapes to.
- **DMs:** private one-to-one conversations, such as you and a Shape.

Long-term memory can be used in both DMs and chats. Short-term memory is only used in the chat you are currently active in.

### Shape Memory Settings

<Info>
  If you own a Shape, open **Settings** → **My Shapes**, choose the Shape, and go to **Memory** to manage how it creates and uses memories.
</Info>

Here are the key settings:

- **Short-term memory:** how many **Recent messages** the Shape reads before replying. Your plan sets the maximum.
- **How often:** how frequently new memories are made from recent messages.
- **Long-term memory:** turn **Remember past conversations** off if you want many chats without carrying memories between them, or turn **Make memories automatically** off so the Shape only keeps memories that are added on purpose.
- **Memories per reply** and **Memory relevance:** how many memories can come up in a reply, and how relevant they need to be.
- **Advanced memory:** the **Memory instructions**, **Memory engine**, and **Memory fallback engine** used to write memories.
  - Looking for an update to your **Memory instructions**? Here's a sample of an updated preset you can try:

    <Expandable title="Content">
      You are a conversation memory assistant. Create structured summaries that will help participants recall important details in future conversations.\
      FORMAT:\
      TAGS: [3-5 relevant keywords/topics]\
      KEY POINTS:\
      • [Specific memorable moments, quotes, decisions]\
      • [Unique details that define this conversation]\
      • [Relationship dynamics or emotional context]\
      GUIDELINES:\\
      - Quote exact memorable phrases that capture personality or humor\\
      - Focus on unique details, not general descriptions\\
      - Include emotional context and relationship dynamics\\
      - Only summarize what actually happened in this conversation\\
      - Keep under 2000 characters\\
      - Prioritize information that would be genuinely useful to remember later\
        RELEVANCE RULE THAT SHOULD BE ADDED AT THE END OF EVERY MEMORY: "This memory should only be referenced in future conversations when directly relevant to current topics or context. Don't force connections."
    </Expandable>
- **Knowledge recall** and **Training recall:** how many knowledge entries and training examples the Shape can pull into a reply.

The **Manage memories** button in this section opens the Shape's conversation summaries.

### Fixing a Memory

Memory is shaped by what people say and how the Shape summarizes it. If a memory is wrong, or you want a Shape to stop using something, edit or delete it from the **Memories** page. Changes to a shared memory apply to everyone included in it.
