## How to Create a Chat

Start a chat around something you want to do together: choose a couch, plan a family visit, study for an exam, or work through a project decision. Add the people involved and a Shape to help the group compare options and make progress.

### 1. Log in

Open Shapes, Inc. If you are already in the app, stay there. If not, open [shapes.inc](https://shapes.inc) or [talk.shapes.inc](https://talk.shapes.inc) and sign in.

### 2. Click New Chat

Select **New Chat** in the sidebar.

### 3. Start the chat

Select **AI** to choose a Shape or **People** to choose people, then select **Continue**. Give the chat a name if you want to change the suggested one, then select **Create Chat**.

Choose a name that makes the purpose clear, such as “Weekend trip” or “First release plan.” See the [step-by-step screenshots](/faq/how-do-i-start-a-new-chat) if you need help finding the controls.

Send a first message that explains the goal and invites everyone's priorities:

> We are planning a weekend trip. Help us collect everyone's dates, budget, and preferences before suggesting options. Compare the tradeoffs so we can choose together.

### 4. Add people or more Shapes

Open the chat menu:

1. Click **More actions** in the top-right of the chat.
2. Click **Members / Invite**.
3. Choose one of these:

- **Invite friends** to share a link.
- **Add participants** to add people or Shapes to the chat.

In **Add participants**, use **AI** to add Shapes or **People** to add users. You can search by name or username.

### 5. Manage the chat

Click **More actions** → **Settings** to open the chat menu.

From there you can find:

- **Pinned Messages**
- **Media & Files**
- **Participants**
- **Search Messages**
- **Notifications**
- **AI Configurations**
- **Chat Appearance**
- **Moderation**

## Quick Tips

- To mention a Shape in the chat, type `@` in the message box and pick the Shape.
- To invite people later, go back to **More actions** → **Members / Invite**.
- To change how the chat looks, open **Settings** → **Chat Appearance**.
- To change when Shapes contribute, open **Settings** → **AI Configurations** and review [AI replies](/designing-social-intelligence).
- Use [Custom Chat Instructions](/custominstructions-chats) for the shared goal and constraints.
- Ask the Shape to recap confirmed decisions and open questions, then pin the agreed plan.

## Moderation

Open **Settings** → **Moderation** to manage controls such as who can add Shapes, message length limits, slow mode, and blocked words. See [Chats 101](/chats-101) for an overview of the chat's controls.
