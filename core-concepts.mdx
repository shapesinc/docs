shapes.inc brings the people making a decision and an AI assistant into the same chat. Everyone can add context, inspect suggestions, and shape the next step.

The goal is an assistant that earns the group's trust, contributes as its own participant, and proactively does useful work. These six building blocks help you configure that experience.

<span id="1-group-chats-are-the-room" />

## 1. Group chats bring everyone together

A chat holds the people, Shapes, and conversation for a shared purpose: a family trip, an apartment decision, a study project, or a team plan.

- Invite the people involved so the assistant can work with their different preferences.
- Put the goal and standing constraints in [chat instructions](/custominstructions-chats).
- Use the chat's notification, moderation, appearance, and credit settings to suit the group. Select the chat's name at the top to open its **Settings**.

See [AI Group Chats](/ai-group-chats) for an example and [Create a chat](/create-a-chat) for the setup steps.

### Two kinds of chat

- **Chat** is for talking things through, without web search, code execution, or other actions.
- **Agent** is for getting tasks done: Shapes can search the web, run code, use apps you've connected, and show their steps under each reply.
- **Auto** chooses Chat or Agent based on each message, so an Auto chat can switch.

Auto is the default. Change it for chats you start with the **New chats** setting on the **Settings** page; chat owners can switch an existing chat under the chat's **Settings** → **AI Configurations**. Private one-to-one conversations are called **DMs**. See [Chat and Agent](/chat-and-agent-modes).

## 2. Shapes are the participants

A **Shape** is a customizable AI assistant with a name, personality, instructions, and a role. One Shape might research options; another might help with writing or learning.

Give the Shape a role that serves the group. Ask it to explain its recommendations, notice missing perspectives, and accept corrections from the people involved. Creator permissions control who can edit the Shape; they do not make the creator's opinion the group's answer.

Start with [What Are Shapes?](/what-are-shapes), then [find one](/how-to-talk-to-shapes) or [make your own](/how-to-make-a-shape).

## 3. Models are the engine underneath

Each Shape runs on an **AI engine**, the model that generates its responses. Instructions define the role; the engine affects reasoning, writing, supported inputs, and skill use. The engine built by shapes.inc appears as **Formless**.

Choose an engine for the task and check its current cost. Some engines are free; premium engines use [Shape Credits](/credits). Features and availability vary by model. To switch engines in a chat, use the composer's **+** menu → **Engine**. To see which engine wrote a reply and what it cost, open **Generation details** from the reply's ⋯ menu.

Use the [AI Engine Guide](/aienginecheatsheet) and the [live engine list](https://shapes.inc/engines). If a response uses credits unexpectedly, check the selected engine, fallback behavior, and [credit settings](/faq/why-is-a-free-engine-costing-credits).

## 4. Memory provides continuity

A Shape can use two kinds of memory, depending on its settings:

- **Short-term memory (STM):** recent messages included in the current context.
- **Long-term memory (LTM):** saved information recalled for later conversations.

This helps a group keep track of preferences, decisions, and recurring constraints. Memory is selective, and context windows have limits. Restate a critical requirement when it matters, and review remembered information when plans change.

Open **More actions** → **Manage memories** in a chat, or **Settings** → **Manage memories** to view, add, edit, and delete personal, chat, and workspace memories. The [Memory Guide](/memory) explains how. [Context Windows](/contextwindows) explains how much information an engine can use at once.

## 5. Participation determines when a Shape contributes

**AI replies** settings help control when Shapes contribute. Chat owners open the chat's **Settings** → **AI Configurations** and review **Auto-reply triggers**. Choose triggers that fit the group's purpose and leave people time to respond. In group Agent chats, Shapes reply when they can help and stay out of ordinary conversation.

The AI replies controls include:

- **Reply when mentioned:** respond when someone addresses the Shape.
- **Keep the convo going:** allow follow-up participation.
- **React to keywords:** respond to configured topics or keywords.
- **Always have something to say:** respond when nobody else replies.
- **Come back later:** allow the Shape to return after a quiet period.

Start with a pace that leaves space for people. In the instructions, explain what makes an interruption useful: an overlooked requirement, new information, or a concrete next step. Proactivity should be judged by the value of the contribution.

See [Designing a Multiplayer Assistant](/designing-social-intelligence) for the controls and suggested setups. See [reply settings](/shapes101#activating-shapes) if a Shape is silent or replies too often.

## 6. Skills let Shapes take action

**Shape Skills** give an assistant capabilities beyond a text response. Depending on the kind of chat, the available skill, and the engine, it can generate an image, research a page, run code, or use a connected service. In Agent chats, built-in skills are included automatically.

To let Shapes use apps like Gmail, Google Calendar, or Notion in Agent chats, connect them under **Settings** → **Connected apps**; see [Connected apps](/connected-apps). Shapes can also work on a computer you link; see [Connect your computer](/connect-your-computer). External MCP servers require setup, supported authentication, and access to the outside service. Connecting one service does not give a Shape access to other people's private accounts. Review the skill's permissions and what it can change before using it in a shared chat.

Follow [Shape Skills](/shapeskills) for setup and troubleshooting. If an action fails, check whether the skill is available, whether the engine supports it, and whether the connection still has the required access.

## Putting it together

For a family trip, create a chat, invite everyone, and add a planning Shape. Share dates, budgets, and preferences. Ask it to compare possible plans, identify the tradeoffs, and draft an itinerary. Update the shared context as people make decisions.

The assistant contributes the research and drafts it can support. The group reviews the result and chooses what to do next.
