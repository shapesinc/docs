When a group is working quickly, small shortcuts help: save a decision to memory without leaving the chat, switch engines mid-conversation, or line up your next question while a Shape is still answering. This page collects the commands, queueing, and shortcuts available in the message box.

## Slash commands

Type **/** in the message box, or open the composer's **+** menu → **Commands**. Keep typing to filter the list, use the arrow keys to move, and press Enter or Tab to choose. Press Esc to close the menu.

You need to be signed in, and commands aren't available in DMs between people.

| Command | What it does |
|---|---|
| `/new` | Start a new chat |
| `/model` | Choose the AI Engine for this chat |
| `/memory` | Open the memories for this chat |
| `/remember` | Save a note to this chat's memory |
| `/compact` | Save this chat to memory so Shapes keep the gist (also available as `/sleep`) |
| `/help` | Ask for help or report a problem |
| `/imagine` | Generate an image with a prompt |
| `/web` | Use web search with a query |
| `/thread` | Start a thread, for example `/thread @shape hi` |

For `/imagine`, `/web`, and `/compact`, you choose which Shape handles the request. See [Memory](/memory) for how saved notes and summaries work, and [Feedback and help](/feedback) for what `/help` opens.

### Chat owner commands

These commands show a **chat owner only** label and appear only for chat owners.

| Command | What it does |
|---|---|
| `/clear` | Clear this chat's short-term memory (also available as `/wack-all`) |
| `/wack` | Reset short-term memory for the Shape you choose |
| `/reset` | Reset long-term memories from this chat for the Shape you choose |
| `/activate` | Activate a Shape to respond to all messages |
| `/deactivate` | Deactivate a Shape to stop auto-responding |
| `/purge` | Delete recent messages from this chat; enter how many |

`/activate` and `/deactivate` aren't offered in a DM with a single Shape.

### Custom commands

The menu also lists **Your custom commands**: reusable instructions you save once and attach with **/**. Select **Manage custom commands →** in the menu to create or edit them. If you haven't saved any yet, the entry reads **Create your first custom command →**.

## Queue a message while a Shape is working

Your message posts right away, even while a Shape is replying. To hold a message for the Shape instead, so it sends after the current reply:

- **Desktop:** press `Cmd+Enter` (Mac) or `Ctrl+Enter` (Windows) while a reply is in progress.
- **Phone:** type your message, then tap the queue button beside Send. It appears while a reply is in progress.

Held messages appear above the message box under **Queued messages**. Select **Send now** to post one immediately, or **Remove** to drop it. When no reply is in progress, `Cmd+Enter` or `Ctrl+Enter` simply sends.

## Keyboard shortcuts

Press `Cmd+/` (Mac) or `Ctrl+/` (Windows), or `?`, to open the **Keyboard shortcuts** list in the app. On Mac, use `Cmd` wherever this table says `Cmd/Ctrl`.

| Shortcut | Action |
|---|---|
| `Cmd/Ctrl+Shift+O` | New chat |
| `Cmd/Ctrl+K` | Search chats |
| `Cmd/Ctrl+B` | Show or hide the sidebar |
| `Shift+Esc` | Focus the message box |
| `Cmd/Ctrl+/` or `?` | Keyboard shortcuts |
| `Ctrl+Shift+1` to `9` | Switch workspace |
| `Ctrl+Shift+[` / `Ctrl+Shift+]` | Previous / next workspace |
| `Enter` or `Cmd/Ctrl+Enter` | Send message |
| `Shift+Enter` | New line |
| `↑` in an empty message box | Edit your last message |
| `Esc` | Close menus or collapse the message box |

Esc also cancels a reply you're writing to a message or an edit, and closes an open thread. On a **Settings** page, Esc takes you back to your last chat.

To open **Settings** in a new tab, Cmd-click (Mac) or Ctrl-click (Windows) it. Links that jump to a message can open in a new tab the same way, and the ⋯ menu next to a chat in the sidebar has **Open in new tab**.

## Phone and touch gestures

- **Reply:** swipe right on a message.
- **Message actions:** tap ⋯ on the message. Pressing and holding selects text.
- **New line:** the Return key adds a new line. Tap Send to send.
- **Take a photo:** open the composer's **+** menu → **Take photo**.
- **Chat actions in the sidebar:** swipe a chat to reveal its ⋯ menu.
- **Reactions:** use the quick reaction strip under a message, or **+** for the full picker.

Haptic feedback is off by default on phones. Turn it on with **Haptic feedback** in **Settings**.

## Desktop tips

- **Attach files:** drop a file anywhere over a chat.
- **Images:** click an image to zoom, and move your pointer to pan. In supported browsers, you can share an image straight from the viewer.
