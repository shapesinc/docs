Slash commands, message queueing, and keyboard shortcuts work from the message box. Use them to save a decision to memory without leaving the chat, switch engines mid-conversation, or line up your next question while a shape is still answering.

## Slash commands

Type **/** in the message box, or open the composer's **+** menu → **Commands**. Keep typing to filter the list, use the arrow keys to move, and press Enter or Tab to choose. Press Esc to close the menu.

You need to be signed in, and commands aren't available in DMs between people.

| Command | What it does |
|---|---|
| `/new` | Start a new chat |
| `/model` | Choose the AI Engine for this chat |
| `/memory` | Open the memories for this chat |
| `/tasks` | See reminders and work shapes are doing for you |
| `/remember` | Save a note to this chat's memory |
| `/compact` | Save this chat to memory so shapes keep the gist (also available as `/sleep`) |
| `/help` | Ask for help or report a problem |
| `/imagine` | Generate an image with a prompt |
| `/web` | Use web search with a query |
| `/thread` | Start a thread with your message, for example `/thread @shape hi` |
| `/btw` | Ask a side question in a thread, for example `/btw is it open late` |

For `/imagine`, `/web`, and `/compact`, you choose which shape handles the request. See [Memory](/memory) for how saved notes and summaries work, [Tasks and reminders](/tasks) for the page `/tasks` opens, and [Feedback and help](/feedback) for what `/help` opens.

See [Threads](/threads) for following replies, keeping shape replies in threads, and what context and access a thread shares with its chat.

### Chat owner commands

These commands show a **chat owner only** label and appear only for chat owners.

| Command | What it does |
|---|---|
| `/clear` | Clear this chat's short-term memory (also available as `/wack-all`) |
| `/wack` | Reset short-term memory for the shape you choose |
| `/reset` | Reset long-term memories from this chat. You choose a shape to run it; in a group chat it clears the chat's long-term memories, whichever shape wrote them |
| `/activate` | Activate a shape to respond to all messages |
| `/deactivate` | Deactivate a shape to stop auto-responding |
| `/purge` | Delete recent messages from this chat; enter how many |

`/activate` and `/deactivate` aren't offered in a DM with a single shape.

### Custom commands

The menu also lists **Your custom commands**: reusable instructions you save once and attach with **/**. Select **Manage custom commands →** in the menu to create or edit them. If you haven't saved any yet, the entry reads **Create your first custom command →**.

A custom command is personal. It appears only in your own menu, in every chat.

#### Write a custom command

1. Type **/** in the message box and select **Manage custom commands →**. You can also open **Settings**, select your name or picture at the top, and find **Commands** on the **Edit profile** page.
2. Select **New command**. With none saved yet, the button reads **Write a command**.
3. Enter a **Name**. The name becomes the command: "Summarize" becomes `/summarize`.
4. Add a **Description** if you want one. It shows next to the command in the menu.
5. Add **Trigger phrases** if you want the command to attach by itself. Separate them with commas. When your message contains one, the command attaches without **/**.
6. Write the **Instructions**: what the shape does when the command is attached.
7. Select **Create command**. A confirmation shows the new command, such as **Saved /summarize**.

For example, instructions for a `/summarize` command:

```text wrap
Summarize the last day of this chat in five bullets. List open questions and who owes what at the end.
```

#### Use a custom command

1. Type **/** and the first letters of the command.
2. Select it under **Your custom commands**. It attaches to your message as a chip in the message box.
3. Type the rest of your message and send it. The shape that replies follows the command's instructions for that message.

To drop a command before sending, select the remove button on its chip. A command attached by a trigger phrase shows **auto** on its chip. Your sent message shows the command as a chip, and other signed-in people in the chat can select **+** on it to save a copy to their own custom commands.

#### Edit or delete a custom command

Open the **Custom commands** list from **Manage custom commands →**. Select the pencil to edit a command, then **Save changes**. Select the trash icon to delete one. Deleting takes effect right away, with no confirmation step.

#### Custom command limits

- **Saved commands:** up to 50. The list shows your count, such as **3/50 saved**.
- **Per message:** up to 5 attached commands.
- **Name:** up to 64 characters, with at least one letter or number. Two of your commands can't share a name.
- **Reserved names:** a name can't match `/activate`, `/deactivate`, `/imagine`, `/purge`, `/reset`, `/sleep`, `/wack`, `/wack-all`, or `/web`. You see "That custom command name is already used by a built-in command."
- **Description:** up to 180 characters.
- **Trigger phrases:** up to 10 per command, each up to 64 characters.
- **Instructions:** required, up to 128,000 characters.

## Queue a message while a shape is working

Your message posts right away, even while a shape is replying. To hold a message for the shape instead, so it sends after the current reply:

- **Desktop:** press `Cmd+Enter` (Mac) or `Ctrl+Enter` (Windows) while a reply is in progress.
- **Phone:** type your message, then tap the queue button beside Send. It appears while a reply is in progress.

Held messages appear above the message box under **Queued messages**. Select **Send now** to post one immediately, or **Remove** to drop it. When no reply is in progress, `Cmd+Enter` or `Ctrl+Enter` sends the message.

If a message you send normally while a shape is answering also needs a reply from that shape, it waits its turn: a shape answers one message at a time in each chat or thread, so that reply shows as **Queued** in the bar above the message box until the current one finishes. See [Follow and stop a reply](/chat-and-agent-modes#see-what-a-shape-did).

## Keyboard shortcuts

Press `Cmd+/` (Mac) or `Ctrl+/` (Windows), or `?`, to open the **Keyboard shortcuts** list in the app. On Mac, use `Cmd` wherever this table says `Cmd/Ctrl`.

| Shortcut | Action |
|---|---|
| `Cmd/Ctrl+Shift+O` | New chat |
| `Cmd/Ctrl+K` | Search chats |
| `Cmd/Ctrl+B` | Show or hide the sidebar |
| `Shift+Esc` | Focus the message box |
| `Cmd/Ctrl+/` or `?` | Keyboard shortcuts |
| `Ctrl+Shift+1` to `9` | Switch workspace |
| `Ctrl+Shift+[` / `Ctrl+Shift+]` | Previous / next workspace |
| `Enter` or `Cmd/Ctrl+Enter` | Send message |
| `Shift+Enter` | New line |
| `↑` in an empty message box | Edit your last message |
| `Esc` | Close menus or collapse the message box |

Esc also cancels a reply you're writing to a message or an edit, and closes an open thread. On a **Settings** page, Esc takes you back to your last chat.

To open **Settings** in a new tab, Cmd-click (Mac) or Ctrl-click (Windows) it. Links that jump to a message can open in a new tab the same way, and the ⋯ menu next to a chat in the sidebar has **Open in new tab**.

## Phone and touch gestures

- **Reply:** swipe left on a message.
- **Message actions:** tap ⋯ on the message. Press and hold a message for actions and reactions, then choose **Select text** to select its text.
- **New line:** the Return key adds a new line. Tap Send to send.
- **Take a photo:** open the composer's **+** menu → **Take photo**.
- **Chat actions in the sidebar:** swipe a chat to reveal its ⋯ menu.
- **Reactions:** use the quick reaction strip under a message, or **+** for the full picker.

Haptic feedback is off by default on phones. Turn it on under **Settings** → **General** → **More preferences** → **Haptic feedback**, on supported touch devices.

## Desktop tips

- **Attach files:** drop a file anywhere over a chat.
- **Images:** click an image to zoom, and move your pointer to pan. In supported browsers, you can share an image straight from the viewer.
