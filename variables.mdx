## Supported variables

1. `{shape}` – Refers to the shape itself.
2. `{user}` – Refers to the user interacting with the shape.

Use these variables in shape editor fields to guide your shape's responses and write presets. To open the editor, go to **Settings** → **Your shapes** and choose your shape.

`{shape}` converts into the shape's name. `{user}` converts into the name of the person the shape is talking to.

### Profile → Basics

- Use `{shape}` and `{user}` in the shape's **Description** to describe who it is and who it's talking to.

### Profile → Greeting, Personality, and Conversation

- Use `{shape}` and/or `{user}` in the shape's **Greeting → First message** to make the first message feel more natural.
- Use variables in fields like **Appearance**, **Story**, and **Conversation goals** for better contextual understanding.
- In **Example chats**, label each line with `{user}:` or `{shape}:` to show how a conversation should go.

### Profile → Response style

- Choose **Custom** under **Response style**, then use variables in **Instructions** to improve your presets' effectiveness.

  See [Presets](/presets) for more.

<span id="4-knowledge" />

### Knowledge

- Use variables to explain knowledge entries and commands.
- Use them to define relationships and command functions more clearly.

<span id="5-images" />

<span id="5-image-engine" />

### Image Engine

- Use `{shape}` in **Image instructions** to define custom image generation rules and styles.

Variables in descriptions, presets, and greetings resolve to the right names in each chat.
