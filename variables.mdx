#### **Supported Variables**

1. `{shape}` – Refers to the shape itself.
2. `{user}` – Refers to the user interacting with the shape.

You can use these variables across various fields in the Shape editor to guide your shape's responses, set presets, and enhance interactions. To open the editor, go to **Settings** → **Your shapes** and choose your shape.

<Info>
  `{shape}` converts into the shape's name. `{user}` converts into the name of the person the shape is talking to.
</Info>

### **Where to Use Variables**

<span id="1-personality-→-core" />

<span id="1-profile-→-basic" />

#### **1. Profile → Basics**

- Use `{shape}` and `{user}` in the shape's **Description** to describe who it is and who it's talking to.

<span id="2-personality-→-traits-story-&amp;-taste-and-conversation" />

<span id="2-profile-→-personality-and-behavior" />

#### **2. Profile → Greeting, Personality, and Conversation**

- You can use `{shape}` and/or `{user}` in the shape's **Greeting → First message** to make the first message feel more natural!
- Use variables in fields like **Appearance**, **Story**, and **Conversation goals** for better contextual understanding.
- In **Example chats**, label each line with `{user}:` or `{shape}:` to show how a conversation should go.

<span id="3-personality-→-response-style" />

<span id="3-profile-→-personality-and-behavior-→-response-style" />

#### **3. Profile → Response style**

- Choose **Custom** under **Response style**, then use variables in **Instructions** to improve your presets' effectiveness.

  <Info>
    [Learn More](/presets) about presets.
  </Info>

#### **4. Knowledge**

- You can use variables to explain knowledge entries and commands.
- And to define relationships and command functionalities more clearly.

<span id="5-images" />

#### **5. Image Engine**

- You can use `{shape}` in **Image Preset** to define custom image generation rules and styles.

<Info>
  By utilizing variables in descriptions, presets, and greetings, you can make your shape more dynamic and engaging!
</Info>
