A shape you create has its own name, role, personality, and knowledge, and you edit it in **Settings** → **Your shapes**. Creating one is optional; you can start with [New chat](/create-a-chat).

Give your shape a clear job: help a study group learn, compare options for a household decision, or contribute to a team project. Describe whose preferences it considers and what useful work looks like.

[How to make a shape](/faq/how-to-make-a-shape) is a shorter walkthrough with screenshots.

## Start a new shape

Sign in at [talk.shapes.inc](https://talk.shapes.inc), then open **Settings** → **Your shapes** → **New shape**.

This opens **Create a shape**. There's currently no limit on how many shapes you can own, on any plan. You can create up to 30 shapes an hour.

<span id="1-describe-the-shape" />

## Describe the shape

Under **Basic**, give the shape a name and a short description. Use the description to state its role in the group: what it helps with, whose preferences it weighs, and how it presents tradeoffs. If the name or description is missing, shapes.inc shows a warning and keeps you on this step.

<span id="2-add-details-optional" />

## Add details (optional)

Open **Advanced** for optional fields such as **Response style**, **Initial message**, **Personality traits**, **Tone**, **Story**, **Likes**, and **Dislikes**. Fill these in now or later in the editor.

- **Response style** sets the length and format of replies. Built-in styles include **Human**, **Short creative**, **Long creative**, **Intelligent**, **Balanced**, and **Unrestricted**, or write your own.
- **Initial message** is the greeting the shape sends to someone new. See [Setting an initial message](/initialmessages).

Select **Set up (1/2)** to save the shape and continue to image setup. If you leave at this point, the shape already appears in **Settings** → **Your shapes**. **Start over** opens a blank form without deleting it.

<span id="3-add-images-and-create" />

## Add images and create

On **Complete your shape**, add a profile picture (required) and a banner (optional). Images can be up to 10MB each. Select **Create**.

Your shape is ready to chat and appears in **Settings** → **Your shapes**. Creating your first shape doesn't send you an automatic helper DM; add the shape to a chat or message it directly to try it.

## Edit your shape

Owners edit a shape in the shape editor. Open it either way:

- **Settings** → **Your shapes**, then select the shape. **Home** → **My Shapes** opens the same list.
- In a chat, select the shape's name or avatar, then **Edit Shape**.

Only owners can open the editor. Shapes [made for a chat](/chat-and-agent-modes#ask-for-a-shape) belong to that chat: its current owners see them in **Your shapes** and can open the full editor. Their owners are the chat's owners.

The editor has these sections:

| Section | What you set |
| --- | --- |
| **Profile** | Avatar and banner; **Basics** for name and description; **Response style**, **Greeting**, **Personality**, **Conversation**, and **Custom messages** |
| **AI Engine** | **AI Engine**, supported reasoning controls, and **Short-term memory** |
| **Memory** | Long-term memory, automatic summaries, recall, and saved conversation memories |
| **Knowledge** | Reference material for the shape's role |
| **Training** | Example exchanges that show how the shape should reply |
| **Voice Engine** | How the shape sounds. See [Give your shape a voice](/how-to-give-your-shape-a-voice) |
| **Image Engine** | **Image Engine**, **Image instructions**, and **Image size** |
| **Share** | Shared-page **Description**, **View public page**, **Make discoverable in search**, and optional **Page customization** |
| **Advanced** | Owners, **Privacy**, **Duplicate**, and **Danger zone** |

Settings to know:

- **Response style** (in **Profile**) sets the length and format of every reply: **Human** (short, casual texts), **Short creative**, **Long creative**, **Intelligence**, **Balanced**, **Unrestricted**, or **Custom**. Choose **Custom** to edit **Instructions**. Built-in instruction text is hidden while that style is selected; existing saved presets are preserved.
- The **Share** section edits the description on the shape's direct page. **Make discoverable in search** is on by default; turn it off to keep the shape out of search, including searches shapes run in Agent chats. Public catalogs and tag discovery are gone and aren't coming back.
- **Reasoning effort** (in **AI Engine**) appears when the shape's engine supports reasoning and **Show internal monologue** is on. It lists only the levels that engine supports, such as **Default**, **Low**, **Medium**, or **High**. Higher effort can take longer and use more credits. These controls do not restore the [former thinking panel](/faq/where-did-the-thinking-panel-go).
- There's no **Timezone** or **Knows the current date** setting. In Agent chats, shapes use your own time.
- Profile images and uploaded voice samples save as soon as their upload succeeds. Other draft changes collect in a bar with **Reset** and **Save**.

If you leave the editor before saving, shapes.inc asks **Discard unsaved changes?** Choose **Keep editing** to go back. If you navigate away or reload, your edits are kept for that browser session and come back the next time you open the shape, with a **Restored your unsaved changes** notice.

To hide or delete a shape, see [Make a shape private](/faq/how-do-i-make-a-shape-private) and [Delete a shape](/faq/how-do-i-delete-a-shape).
