Give your assistant a clear job: help a study group learn, compare options for a household decision, or contribute to a team project. Describe whose preferences it should consider and what useful work looks like.

For a shorter walkthrough with screenshots, see [How to make a Shape](/faq/how-to-make-a-shape).

## Start a new Shape

Sign in at [talk.shapes.inc](https://talk.shapes.inc), then use any of these:

- **Settings** → **My Shapes** → **New shape**
- **Home** → **Create Shape**, next to **My Shapes**
- **New Chat** → **New Shape**
- In a chat, open its **Settings** → **Participants** → **Create shape**

Each one opens **Create a shape**. Your plan sets how many Shapes you can own; if you've reached the limit, the page tells you, and you can delete a Shape or upgrade to make another.

## 1. Describe the Shape

Under **Basic**, give the Shape a name and a short description. Use the description to explain its role in the group: what it helps with, whose preferences it should weigh, and how it should present tradeoffs. If the name or description is missing, shapes.inc shows a warning and keeps you on this step.

## 2. Add details (optional)

Open **Advanced** for optional fields such as **Response style**, **Initial message**, **Personality traits**, **Tone**, **Story**, **Likes**, and **Dislikes**. You can fill these in now or later in the editor.

- **Response style** sets the length and format of replies. Built-in styles include **Human**, **Short creative**, **Long creative**, **Intelligent**, **Balanced**, and **Unrestricted**, or write your own.
- **Initial message** is the greeting the Shape sends to someone new. See [Setting an initial message](/initialmessages).

Select **Set up (1/2)** to continue.

## 3. Add images and create

On **Complete your shape**, add a profile picture (required) and a banner (optional). Images can be up to 10MB each. Select **Create**.

Your Shape is ready to chat and appears in **Settings** → **My Shapes**. Creating your first Shape doesn't send you an automatic helper DM; add the Shape to a chat or message it directly to try it.

## Edit your Shape

Shape owners edit everything in one place, the Shape editor:

- **Settings** → **My Shapes**, then select the Shape. **Home** → **My Shapes** opens the same list.
- In a chat, select the Shape's name or avatar, then **Edit Shape**.

Only owners can open the editor. Shapes created for a chat also appear in **My Shapes** for every current member of that chat; selecting one opens that chat.

The editor has these sections:

| Section | What you set |
| --- | --- |
| **Profile** | Avatar and banner, **Basics** (**Name**, **Tagline**, **Description**), **Discovery** (**Category**, tags), and **Shape details** |
| **Personality** | **Core** (**Description**, **Greeting**), **Response style**, **Traits**, **Story & taste**, **Conversation**, and **Command replies** |
| **AI Engine** | **Main engine**, **Premium engine**, **Fallback engine**, **Show reasoning** and **Reasoning effort** (for engines that support reasoning), and **Language & time** |
| **Memory** | **Short-term memory**, **Long-term memory**, **Remember past conversations**, **Make memories automatically**, and recall settings |
| **Knowledge** | Reference material for the Shape's role |
| **Training** | Example exchanges that show how the Shape should reply |
| **Voice** | How the Shape sounds. See [Give your Shape a voice](/how-to-give-your-shape-a-voice) |
| **Images** | Image engine, style and size, and the text trigger for image requests |
| **Stats** | Messages sent and people reached |
| **Manage** | **Visibility & safety**, **Duplicate**, **About**, and **Danger zone** |

A few settings worth knowing:

- **Response style** (in **Personality**) sets the length and format of every reply: **Human** (short, casual texts), **Short creative**, **Long creative**, **Intelligent**, **Balanced**, **Unrestricted**, or **Custom**. Editing the style's **Instructions** switches it to **Custom**. A Shape that already used a preset keeps it.
- **Category** (in **Profile** → **Discovery**) includes **Chat shape** for a general conversational Shape.
- **Reasoning effort** (in **AI Engine**) appears when the Shape's engine supports reasoning and **Show reasoning** is on. It lists only the levels that engine supports, such as **Default**, **Off**, **Low**, **Medium**, or **High**. Higher effort can take longer and use more credits.
- Profile images save as soon as you add them. Other changes collect in a bar with **Discard** and **Save**.

<Tip>
  If you leave the editor before saving, shapes.inc asks **Discard unsaved changes?** Choose **Keep editing** to go back. If you navigate away or reload, your edits are kept for that browser session and come back the next time you open the Shape, with a **Restored your unsaved changes** notice.
</Tip>

To hide or delete a Shape, see [Make a Shape private](/faq/how-do-i-make-a-shape-private) and [Delete a Shape](/faq/how-do-i-delete-a-shape).
