Presets are reusable instructions that guide how shapes respond. Choose the scope that fits: replies to you, everyone in a chat, or an individual shape.

<span id="what-do-the-chat-templates-mean" />

## What the chat templates do

Templates are built-in instructions for how shapes reply in a chat. In **Preset Templates** they're grouped: **Casual** keeps it conversational, **Smart** focuses on research and explaining, and **Creative** covers creative writing. Creative templates and a few Casual ones apply only when you're just chatting with a shape; the rest apply to every reply. See [Custom chat instructions](/custominstructions-chats). When you create a chat, **More options** → **Templates** lists the same templates by name. Their text is hidden; try one to see how it replies. To write your own, choose **Custom instructions** in **Preset Templates**, or use the **Chat Instructions** box when you create a chat.

| Group | Templates | Applies to |
| --- | --- | --- |
| **Creative** | Skilled creative, Long creative, Action, Atmosphere, Short creative, Crazy, Uncensored Mode | Just chatting with a shape |
| **Casual** | Human, Natural, Texting | Just chatting with a shape |
| **Casual** | Skilled Helper, Supportive, Balanced | Every reply |
| **Smart** | Research Mode, Expert Assistant, Intelligence, Concise Expert, Socratic, Teacher, Deep Research | Every reply |

When you ask a question or for something to be done, the shape answers without the just-chatting templates. A template you edit, and instructions you write yourself, apply to every reply.

## Key elements

A preset uses two keywords:

- `{shape}`: Refers to the shape.
- `{user}`: Refers to the user interacting with the shape.

Keep "shape" and "user" lowercase.

## Where to use presets

A preset applies in three places:

- **Your preset:** open **Settings** → **Personalization** → **Your preset**. Pick a template from **Preset Templates**, or select **Custom instructions** to edit the current instructions, up to 8,000 characters. It applies to replies to you in every chat, alongside that chat's instructions. See [Personalization](/personalization).
- **A chat's Instructions:** open **More actions** (⋯) in the chat header → **Instructions**, or the chat's **Settings** → **AI settings** → **Instructions**. These apply to everyone in the chat. Where **Preset Templates** is shown, select a template or **Custom instructions** to edit the current instructions. Where there is no template picker, write directly in the instructions box. Chat owners can edit them, and so can you in a DM with a shape.
- **A shape's response style:** if you own the shape, open **Settings** → **Your shapes**, choose the shape, and open **Profile** → **Response style**. Choose a built-in style, or select **Custom** to write your own.

Built-in choices remain available, but their instruction text stays hidden while a built-in is selected. Custom instructions remain editable.

## Create your own presets

Describe how you want the shape to respond. Use the format:

```
{shape} [your instruction here]. {shape}'s [additional instruction if needed].
```

For more on writing presets, see [Write a shape's personality and instructions](/write-a-shape).
